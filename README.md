# PC Creator Simulator

Горизонтальная 2D-игра про сборку ПК на **Kotlin Multiplatform + Compose Multiplatform**. Работает на Android и Desktop; сборка APK, Windows EXE и Linux app-image выполняется через GitHub Actions.

## Что внутри

- Главное меню и горизонтальная мастерская;
- правое меню разделов: **Главная**, **Задания**, **Сборка ПК**, **Магазин**;
- отдельные заказы клиентов с клиентом, описанием, бюджетом, минимальной производительностью и бонусом;
- уровень продавца, XP, рейтинг от 1 до 5 звёзд и счётчик выполненных заказов;
- тёплая палитра мастерской: дерево, графит, зелёная PCB, медные акценты вместо сплошного синего;
- 2D Canvas-сцена открытого корпуса с CPU/RAM/GPU/SSD/PSU-слотами;
- выбор детали в магазине → установка в соответствующий слот;
- POST-проверка сокета CPU, типа DDR, мощности БП, бюджета клиента и обязательных компонентов;
- аренда мастерской, прибыль, репутация, разблокировка дорогих комплектующих.

## Игровой цикл

1. В **Заданиях** выбери заказ клиента.
2. В **Магазине** выбери комплектующие.
3. В **Сборке ПК** установи детали нажатием на соответствующие слоты корпуса.
4. Нажми **POST / Собрать**, затем **Продать**.
5. Получи деньги и XP, подними рейтинг и открой более дорогие детали.

## Запуск и сборка

JDK 17 и Gradle 8.9:

```bash
gradle :composeApp:run
gradle :composeApp:assembleDebug
gradle :composeApp:createDistributable
```

Android запускается в landscape-режиме; desktop-окно стартует размером 1280×800.

## GitHub Actions

`.github/workflows/build.yml` запускает:

- `pcsim-android-apk` — debug APK;
- `pcsim-windows-exe` — Windows app-image с EXE;
- `pcsim-linux-binary` — Linux app-image.

Тег `v*` дополнительно создаёт GitHub Release.
